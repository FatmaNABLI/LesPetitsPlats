# Les Petits Plats

Application web de recherche de recettes développée avec **JavaScript**.

Le projet consiste à créer une interface de recherche permettant de trouver des recettes à partir de différents critères et de mettre en œuvre un algorithme de recherche performant.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap
- JSON
- Git / GitHub

## ✨ Fonctionnalités

- Affichage dynamique des recettes
- Recherche de recettes
- Filtrage des résultats à partir de plusieurs critères
- Gestion des données provenant d'un fichier JSON
- Interface responsive

## ⚡ Algorithmes et performances

- Développement de deux algorithmes de recherche en JavaScript
- Comparaison de leurs performances
- Optimisation de l'algorithme retenu

## 💡 Compétences développées

- Analyse et résolution d'un problème algorithmique
- Manipulation et filtrage de données en JavaScript
- Optimisation des performances
- Comparaison d'algorithmes
- Développement d'une interface responsive
- Utilisation de Git et GitHub
